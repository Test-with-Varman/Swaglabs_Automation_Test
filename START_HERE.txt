✅ PREREQUISITES FOR PARALLEL EXECUTION
═════════════════════════════════════════════════════════════════════════════════

Before running parallel tests, ensure:

✓ Each @BeforeMethod initializes a fresh driver
✓ Each @AfterMethod properly quits the driver
✓ No shared driver instances between threads
✓ Tests are independent (no shared test data)
✓ At least 8GB RAM (4GB minimum)
✓ Multi-core CPU (4+ cores recommended)
✓ Application can handle 3+ simultaneous users


🆘 QUICK TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: Tests fail in parallel but pass sequentially
  → Solution: Ensure each thread has its own driver instance

PROBLEM: "Port already in use"
  → Solution: Check @AfterMethod contains driver.quit()

PROBLEM: Out of memory
  → Solution: Reduce thread count from 3 to 2

PROBLEM: Tests timeout
  → Solution: Reduce thread count or increase timeout

PROBLEM: Report not generated
  → Solution: Check test-output folder permissions
